# Mi Día con Dios — Android MVP

Primera versión funcional de una app devocional cristiana diaria.

## Incluye
- Inicio con versículo, reflexión y oración del día.
- Botón para completar el devocional.
- Racha diaria guardada localmente.
- Mis oraciones (crear/eliminar, persistencia local).
- Diario de gratitud (crear/eliminar, persistencia local).
- Favoritos de ejemplo.
- Planes de lectura de ejemplo.
- Eventos e Iglesia de ejemplo.
- Navegación inferior.
- Diseño inspirado en el mockup aprobado.

## Tecnología
- Kotlin
- Jetpack Compose
- Material 3
- Navigation Compose
- SharedPreferences para el MVP

## Compilar
- APK de prueba: `gradle assembleDebug`
- AAB de publicación: `gradle bundleRelease`

## Identificador provisional
`com.modu.midiacondios`

El repositorio incluye un workflow de GitHub Actions para generar automáticamente un APK de prueba en la nube.
